# 订单量（总订单数）

## 业务定义
统计周期内**所有状态**的订单笔数，含已取消、已退款、待发货。

## 计算逻辑
```
订单量 = COUNT(订单)
```

## 与有效订单量的区别
| 指标 | 计入范围 | 用途 |
| --- | --- | --- |
| 订单量 | 全部订单 | 看流量 / 下单意愿 |
| 有效订单量 | 仅已完成且未退款 | 看真实成交 |

退款率 = 退款订单数 / 订单量，因此订单量是退款率的分母。

## 常见误解
- ❌ 把订单量当成成交笔数对外汇报。
- ❌ 用订单量作客单价分母。

## 示例问法
- 「近 7 日订单量」
- 「各城市订单量与有效订单量对比」
