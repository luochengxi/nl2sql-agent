# 及时妥投率

## 业务定义
统计周期内，在**承诺时效内签收**的已签收运单占全部已签收运单的比例。

## 计算逻辑
```
及时妥投率 = 及时签收运单数 / 已签收运单数
```
承诺时效：同城 24 小时、跨城 48 小时。未签收运单不进入分子与分母。

## 口径边界
- 结果以小数返回（0.9234），展示时格式化为百分比（92.34%）。
- 分母为 0 时返回 NULL。

## 常见误解
- ❌ 用「全部发货单」做分母：未签收单会被算作不及时，指标虚低。
- ❌ 与「妥投率」（签收率）混淆：妥投率分母是发货单，及时妥投率分母是已签收单。

## 示例问法
- 「近 7 日及时妥投率」
- 「各城市及时率排名」
