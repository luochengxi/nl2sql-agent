# 同比 / 环比（对比口径）

## 环比（MoM / WoW / DoD）
与**紧邻的上一个等长周期**比较。例如「近 7 日环比」= 本 [T-7, T-1] 对比上 [T-14, T-8]。

## 同比（YoY）
与**去年同一自然周期**比较。例如「本月同比」= 本月 [M1, T-1] 对比去年同月对应区间。

## 计算逻辑
```
对比周期 = 当前周期整体平移（环平移一个周期长度 / 同平移一年）
增长率   = (本期值 - 对比期值) / 对比期值
```
对比期值为 0 或 NULL 时，增长率返回 NULL（不显示 +∞）。

## 常见误解
- ❌ 环比用「昨天」单日对比「近 7 日」：周期长度必须一致。
- ❌ 同比按 365 天平移：应按自然月/自然周对齐，避免星期错位。
- ❌ 对比期分母为 0 时显示 0% 或 100%。

## 示例问法
- 「近 7 日有效订单量环比」
- 「本月销售额同比」
