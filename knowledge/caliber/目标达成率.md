# 目标达成率

## 业务定义
统计周期内实际 GMV 与目标 GMV 的比值，用于经营目标考核。

## 计算逻辑
```
目标达成率 = SUM(实际GMV) / SUM(目标GMV)
```
先分别汇总再相除，**不是**各店达成率的算术平均（避免小店权重被放大）。目标为 0 时返回 NULL。

## 口径边界
- 实际 GMV 取绩效考核口径（含分摊），与零售线「销售额」不同。
- 结果以小数返回（1.056 → 105.60%）。

## 常见误解
- ❌ 用各店达成率求平均：应按 GMV 加权。
- ❌ 与零售线销售额混用：口径不同，跨业务线对比无意义。

## 示例问法
- 「本月各区域目标达成率」
- 「华东达成率多少」
