# 销售额（GMV / 支付金额）

## 业务定义
统计周期内有效订单的**实付金额**合计，不含运费、不含平台补贴，不含已退款订单金额（退款通过退款率单独衡量）。

## 计算逻辑
```
销售额 = SUM(有效订单.实付金额)
```

## 口径边界
- 计入：所有有效状态订单的实付金额（含已退款），口径与「有效订单量」相同，可直接相除得到客单价。
- 不计入：运费、平台优惠券补贴、押金、售后补款。
- 币种：人民币（¥），单位元，保留 2 位小数。

## 常见误解
- ❌ 与绩效线的「绩效销售额」混淆：绩效线用的是考核口径的 GMV（含目标分摊），**同名不同口径**。遇到「销售额」而未指明业务线时应向用户澄清。

## 示例问法
- 「近 7 日华东销售额」
- 「各城市销售额对比」

## 关联指标
客单价、有效订单量、退款率
