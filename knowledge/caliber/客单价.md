# 客单价

## 业务定义
统计周期内**平均每笔有效订单**的实付金额，用于衡量单笔消费水平。

## 计算逻辑
```
客单价 = SUM(实付金额) / 有效订单量
```
分母为 0 时返回 NULL，不返回 0。

## 口径边界
- 分子：全部订单实付金额（与销售额口径一致）。
- 分母：有效订单量（已完成、未取消未退款）。
- 单位：元，保留 2 位小数。

## 常见误解
- ❌ 用「总订单量」做分母：会把取消/退款单摊薄，客单价虚低。
- ❌ 分母为 0 时填 0：应显示「无有效订单」而非 0 元。
- ❌ 把平均商品单价当成客单价。

## 示例问法
- 「近 7 日客单价」
- 「各城市客单价对比」
