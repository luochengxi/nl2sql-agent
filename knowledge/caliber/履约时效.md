# 平均履约时效

## 业务定义
统计周期内，从**发货**到**客户签收**的平均耗时，单位小时。

## 计算逻辑
```
平均履约时效 = AVG(签收时间 - 发货时间)  -- 小时
```
未签收的运单**不纳入**平均值计算（分母只含已签收运单）。

## 口径边界
- 起算点：仓库出库打单时间，不是用户下单时间。
- 终点：客户签收时间，不是配送员妥投上报时间。
- 跨天按自然小时累计，不做工作日折算。

## 常见误解
- ❌ 用「下单 → 签收」计算：那是全链路时长，包含备货时间。
- ❌ 把未签收运单按 0 小时计入：会显著拉低平均值。

## 示例问法
- 「近 7 日平均履约时效」
- 「各区域履约时效对比」
